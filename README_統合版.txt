統合版 Discord Bot
==================

このパッケージは次の3つを1つのDiscord Botへ統合しています。
- にゃんこ大戦争: main13.py（今回アップロードされた最新版を基準）
- ぷにぷに: modules/ywp と cogs/ywp.py（イベント／強敵ステージID自動取得の修正版）
- ツムツム: modules/tsum_modern と cogs/tsum_modern.py（最新のコイン・プレイヤーレベル・スコア・メダル指定版）

起動前
------
1. 既存環境のBCSFE、Nyanko_*セーブ素材、必要な外部ファイルを main13.py と同じプロジェクトに配置してください。
2. 環境変数 DISCORD_BOT_TOKEN を設定してください（main13.py既存設定）。
3. ツムツムの LOG_CHANNEL_ID を使う場合は環境変数 LOG_CHANNEL_ID を設定してください。
4. modules/ywp/config.json を config.json.example から作成し、ぷにぷにの設定を入れてください。
5. pip install -r requirements-all.txt を実行し、python main13.py で起動してください。

主な追加コマンド
----------------
- にゃんこ大戦争: 既存の main13.py コマンドを維持
- ぷにぷに: /パネル設置 など、既存のぷにぷにコマンド
- ツムツム: /ツムツム代行 /ツムツム無料30万 /ツムツム状態

注意
----
- 3ゲームのDiscordコマンドを同じBotへ登録します。コマンド名が重複しないよう、旧ツムツムCogではなく最新のツムツム実装を登録しています。
- 本ZIPにはトークン等の秘密情報は含めていません。各ゲームAPIやBCSFEに必要な依存関係・既存セーブ素材は実行環境側で用意してください。
- ステージID自動取得はマスタからの分類に基づきます。強敵のID形式が今後別系統になった場合、完全な自動分類は保証できません。
